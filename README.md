One funny line of awkward small talk that one robot says to another while they ride an elevator together. A judge model compares entries two at a time and the funniest line takes the reward: the top 10 lines share $10, and entry is free.

## Run it

```sh
python3 main.py
```

The program writes one funny line (103 characters) to `/output/entry.txt`:

> According to my sensors, we have avoided eye contact for 43 seconds. New record. Please do not ruin it.
